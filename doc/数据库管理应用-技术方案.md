# 数据库管理应用技术方案（对标 Navicat）

> 文档版本：v0.2 · 时间：2026-08-15（已确认关键决策）
> 目标：实现一个可对标 Navicat Premium 的数据库管理工具，覆盖连接管理、对象设计、SQL 开发、数据操作、同步迁移、备份恢复、建模、自动化、监控等核心能力，并重点保障**性能**与**安全**。
>
> **已确认决策**（用户 2026-08-15）：
> - 交付形态：**桌面 + Web 同源**——同一 NestJS 后端，Tauri 作桌面壳，Web 亦可直接访问。
> - 首批数据库：**全量 7 种**——MySQL / MariaDB / PostgreSQL / SQLite / Oracle / SQL Server / MongoDB（Redis 视情况增量）。
> - 后端栈：**Node.js（NestJS）**——驱动最成熟，落地最快。

---

## 一、目标与范围

- **定位**：跨数据库的统一管理客户端（DBA / 开发 / 数据分析师通用）。
- **对标对象**：Navicat Premium（多数据库统一管理），而非单库专用版（Navicat for MySQL 等）。
- **三大硬指标**：
  1. **功能完整度**：覆盖 Navicat 90%+ 常用模块。
  2. **性能**：千万级结果集秒开、导入导出不卡 UI、多连接并发稳定。
  3. **安全**：凭据不落盘明文、传输加密、操作可审计、误操作可防。

## 二、Navicat 功能完整清单（按模块梳理）

### 2.1 连接与安全管理
- 多数据库统一连接（MySQL / MariaDB / PostgreSQL / SQLite / Oracle / SQL Server / MongoDB / Redis 等）
- 连接分组、颜色标签、虚拟分组
- 连接配置导入/导出（含团队共享）
- 接入方式：SSH 隧道、HTTP/HTTPS 通道、SSL/TLS 加密、Windows 集成认证、Kerberos、PAM、GSSAPI
- 连接测试、断线重连、连接保活
- 凭据加密存储（ vault / 系统钥匙串）

### 2.2 对象 / 结构设计（可视化 Designer）
- 表设计器：字段、类型、默认值、注释、自增、主键
- 索引管理、外键（约束）管理、唯一约束、检查约束
- 视图设计器、物化视图
- 存储过程 / 函数 / 触发器 / 事件（Event）设计器
- 分区表（Partition）管理
- 用户与权限管理（库/表/列级授权）
- DDL 一键查看 / 复制 / 导出
- 对象依赖关系查看

### 2.3 数据操作
- 表格化数据浏览（网格视图），内联增/删/改
- 排序、筛选、查找、替换、高亮
- 大数据集虚拟滚动 + 分页/游标加载
- 批量更新/插入/删除向导
- 数据格式化与显示选项（二进制、JSON、地理等）
- 字段注释显示

### 2.4 SQL 开发与查询
- SQL 编辑器：语法高亮、行号、代码折叠、书签
- 智能自动补全（表名/字段名/函数名/关键字，按方言切换）
- 代码片段（Snippet）自定义
- 可视化查询构建器（Query Builder，拖拽 JOIN/条件/分组）
- 多标签页，每个窗口独立事务（提交/回滚）
- 执行计划可视化（EXPLAIN / EXPLAIN ANALYZE）
- 查询历史与收藏、模糊检索
- PL/SQL、T-SQL 调试器（断点、单步、变量监视、调用栈）
- 结果集导出（Excel/CSV/HTML/XML/JSON/SQL Insert 等十余种）

### 2.5 数据迁移与同步
- 数据传输（Data Transfer）：跨库/跨类型全量与增量迁移
- 结构同步（Structure Sync）：比对差异 → 生成 ALTER 脚本 → 预览执行
- 数据同步（Data Sync）：记录级比对 → 生成 INSERT/UPDATE/DELETE 合并脚本
- 冲突策略：源优先 / 目标优先 / 时间戳优先 / 手动确认
- 字段映射、过滤条件、增量条件
- 迁移前数据校验（记录数、校验和）

### 2.6 备份与恢复
- 逻辑备份（SQL 文件）/ 物理备份（mysqldump、pg_dump、Oracle Data Pump、SQL Server 备份）
- 备份压缩 + AES-256 加密、断点续备、备份集校验
- 全量 / 增量备份、定时计划
- 远程存储（FTP/SFTP/云对象存储）
- 选择性还原、事务回滚保护、恢复预览

### 2.7 数据建模（ER 图）
- 正向工程：拖拽建表/字段/索引 → 生成 DDL
- 逆向工程：从现有库自动生成 ER 图，识别主外键
- 模型对比与同步、版本管理
- 图层/布局/配色、导出 PNG/PDF/SVG

### 2.8 报表与自动化
- 报表生成器（交互式设计、导出 PDF/Excel）
- 自动化调度（Auto Run）：定时备份、同步、报表、脚本
- 任务日志、邮件通知

### 2.9 运维监控
- 服务器监控面板：连接数、QPS、慢查询、锁等待、缓冲池命中率
- 会话/进程管理（kill 会话）
- 复制拓扑可视化、复制延迟监控（MySQL）

### 2.10 云协作

- 团队成员权限管理、共享项目

```
└───────────────────────────┬─────────────────────────────────┘
                            │  HTTPS / WebSocket (长查询流式)
┌───────────────────────────┴─────────────────────────────────┐
│                    后端服务 (应用核心)                         │
│  ┌────────────┐ ┌────────────┐ ┌──────────────────────────┐ │
│  │ 连接管理    │ │ 查询引擎    │ │ 元数据抽象层(统一模型)     │ │
│  │ 池化/SSH/TLS│ │ 流式/分页/  │ │ 方言适配器(MySQL/PG/... ) │ │
│  │ 凭据保险库  │ │ 取消/超时   │ │ 差异对比(diff)引擎         │ │
│  └────────────┘ └────────────┘ └──────────────────────────┘ │
│  ┌────────────┐ ┌────────────┐ ┌──────────────────────────┐ │
│  │ 导入导出管道│ │ 调度器      │ │ 审计/安全网关(查询守卫)    │ │
│  │ 流式解析    │ │ 自动化任务  │ │ 脱敏/只读模式/操作日志     │ │
│  └────────────┘ └────────────┘ └──────────────────────────┘ │
└───────────────────────────┬─────────────────────────────────┘
                            │  原生驱动 / 协议
        ┌──────────┬────────┴───────┬──────────┬──────────┐
      MySQL     PostgreSQL    Oracle    SQL Server   SQLite/Mongo
      (SSH/SSL)   (SSH/SSL)  (TNS/SSL)  (Integrated)  (文件)
```

**分层职责**
1. **连接层**：连接池 + SSH 隧道 + TLS + 凭据保险库。
2. **元数据抽象层**：把不同库的 schema 映射成统一对象模型，屏蔽方言差异。
3. **查询执行引擎**：参数化执行、流式返回、可取消、超时、只读分析模式。
4. **工具层**：导入导出、同步/迁移 diff、调度、建模、监控、审计。

| 层 | 推荐方案 | 理由 | 备选 |
|---|---|---|---|
| 外壳/分发 | **Tauri (Rust) 桌面壳 + Web 同源** | 同一 NestJS 后端，桌面用 Tauri 封装（系统钥匙串存凭据），Web 直连同一服务 | Electron（重） |

| 表格 | TanStack Table + TanStack Virtual | 千万行虚拟化不卡 | AG Grid |
| SQL 编辑器 | Monaco Editor + 方言语言包 | 智能补全/高亮/折叠 | CodeMirror 6 |
| 后端 | **Node.js (NestJS)**（驱动最成熟） | mysql2/pg/mssql/oracledb/mongodb 全齐 | Rust(Axum+sqlx，性能/安全更优但 Oracle/Mongo 支持弱) |

| 建模画布 | React Flow / Konva | 拖拽 ER 图 | — |
| 加密 | AES-256-GCM + OS Keychain | 凭据保险库 | KMS |

## 六、关键模块设计

### 6.1 连接与凭据安全
- 连接配置入库前，密码/私钥用 **AES-256-GCM** 加密；密钥存放于 **系统钥匙串**（Windows Credential Manager / macOS Keychain），不写明文文件。
- SSH 隧道用 ssh2；TLS 校验服务端证书（可选关闭，但默认开启并告警）。
- 支持凭据引用环境变量 / 外部密钥（KMS），避免硬编码。

### 6.2 统一元数据抽象层
- 定义统一模型：`Database / Schema / Table / View / Column / Index / ForeignKey / Procedure / Function / Trigger / Event`。
- 每类数据库一个 `DialectAdapter` 实现 `introspect()` / `generateDDL()` / `translateType()`，新增库只需补适配器。

### 6.3 查询执行引擎（性能核心）
- **流式返回**：用驱动的游标/流式接口，边取边推给前端，避免整表载入内存。
- **分页/键集**：大数据集用 keyset pagination（基于有序键），优于 offset 深翻页。
- **可取消**：每个查询持有 abort handle，前端可终止。
- **超时与资源上限**：单查询行数/内存上限，超限截断并提示。
- **只读模式**：连接可标记为"分析只读"，自动拦截 DDL/DML。

### 6.4 数据网格（虚拟化）
- 仅渲染视口内行（TanStack Virtual），支持百万级流畅滚动。
- 内联编辑走"待提交事务"，批量确认后一次性提交，失败可回滚。

### 6.5 导入导出管道
- 后端 Worker 线程流式解析/写出，UI 显示进度，不阻塞主线程。
- 字段映射向导、编码自动检测、空值/转义策略可配。
- 导入先落临时表 → 校验 → 合并，降低误写风险。

### 6.6 同步 / 迁移 Diff 引擎
- 结构 diff：比对两端元数据模型 → 生成 ALTER 脚本，执行前可预览。
- 数据 diff：按主键比对 → 生成 INSERT/UPDATE/DELETE；冲突策略可配。
- 迁移前自动校验记录数与校验和。

### 6.7 建模（ER）
- 反向工程：元数据 → 节点/边 → 自动布局。
- 正向工程：画布 → DDL → 可同步到库。

### 6.8 自动化调度 & 监控
- 调度器按 cron 触发备份/同步/报表，任务日志 + 失败邮件通知。
- 监控读取数据库系统视图（如 `pg_stat_*`、`information_schema`、`performance_schema`），实时刷新。

## 七、性能设计要点

1. **连接池**：按库类型独立池（上限可配），复用连接，减少握手开销。
2. **结果集虚拟化**：前端只渲染可见行，内存恒定。
3. **流式 IO**：查询、导入、导出全程流式，避免全量驻留内存。
4. **异步非阻塞**：后端事件循环 / Worker 线程，长任务不卡 UI。
5. **键集分页与 EXPLAIN 建议**：深翻页不退化；编辑器内联索引建议。
6. **可取消 + 超时 + 上限**：防止单查询拖垮客户端与服务端。
7. **本地缓存**：元数据/表结构可缓存（TTL），减少重复 introspect。

---

## 八、安全设计要点

1. **凭据保险库**：AES-256-GCM 加密 + 系统钥匙串，绝不明文落盘。
2. **传输加密**：SSH/TLS 默认开启，证书校验，弱配置显式告警。
3. **查询守卫（防误操作）**：
   - 语句分类（读 / 写 / DDL），写/DDL 在只读连接直接拒绝；
   - 高危操作（DROP/TRUNCATE/DELETE 无 WHERE）需二次确认或禁止；
   - 可选"安全模式"全局拦截破坏性语句。
4. **参数化执行**：应用自身生成的 SQL 全部走参数绑定，杜绝注入。
5. **最小权限**：仅使用连接提供的账号权限，应用不做提权。
6. **审计日志**：连接/查询/结构变更/数据变更全量留痕，可按用户+时间检索。
7. **PII 脱敏**：网格对标记字段（手机号/身份证/邮箱）按策略掩码。
8. **命令注入防护**：调用 mysqldump/pg_dump 等外部工具时，参数白名单化，禁止 shell 拼接。
9. **Web 模式**：会话超时、操作需鉴权、敏感接口限流。

## 十、风险与开放问题（已收敛）

- **全量 7 库驱动成熟度**：MySQL/MariaDB/PostgreSQL/SQLite 驱动最成熟，P0 即可打通；Oracle(`oracledb`)/SQL Server(`mssql`)/MongoDB(`mongodb`)/Redis(`ioredis`) 驱动可用但方言细节多，按 DialectAdapter 增量接入，P0 先完成接口与 SQLite 可用、其余留 stub。
- **桌面 + Web 同源的安全分叉**：Web 模式必须补全鉴权/会话超时/接口限流；桌面模式凭据走系统钥匙串。两者共用后端，安全中间件统一挂载。
- **断点续备 / 物理备份**：依赖各库原生工具（mysqldump/pg_dump/Data Pump），需处理跨平台二进制分发，放 P1/P2。
- **决策已确认**：① 桌面+Web 同源 ② 全量 7 库 ③ Node(NestJS)。
